# WP Dev Toolkit Utilities

This directory contains utility functions and helper classes for the WordPress Development Toolkit.

## Files

- `Helpers.php`: Provides helper functions and utilities used throughout the plugin

## Purpose

The Utilities components provide common functionality that doesn't fit into other categories. These include:

1. Helper functions for logging
2. Formatting utilities
3. Plugin data retrieval helpers

The code in this directory is designed to be reused across different parts of the plugin, providing consistent functionality where needed.
