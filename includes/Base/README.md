# WP Dev Toolkit Base Components

This directory contains base classes and interfaces used throughout the WordPress Development Toolkit.

## Files

- `ToolBase.php`: Abstract base class that all toolkit tools extend
- `ToolInterface.php`: Interface that defines required methods for toolkit tools

## Purpose

The Base components provide common functionality and standardized interfaces to ensure consistency across the plugin. By
using these base classes and interfaces, we create a more maintainable and extensible codebase where all tools follow
the same patterns.
