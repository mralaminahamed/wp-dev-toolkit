# WP Dev Toolkit Core Components

This directory contains core functionality for the WordPress Development Toolkit.

## Files

- `Config.php`: Handles plugin configuration storage and retrieval
- `Logger.php`: Provides logging functionality
- `Plugin.php`: Main plugin controller class

## Purpose

The Core components are the foundation of the plugin, managing configuration, initialization, and coordinating between different plugin parts. These classes are responsible for:

1. Loading and saving plugin settings
2. Initializing tools and controllers
3. Registering hooks and filters
4. Coordinating the plugin lifecycle
