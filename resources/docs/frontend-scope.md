# WP Dev Toolkit - Frontend Scope

This directory contains all frontend asset management and related functionality.

## Files

### Assets.php

- **Purpose**: Manages registration and enqueuing of CSS, JavaScript, and other frontend assets
- **Responsibilities**:
  - Register and enqueue React application scripts
  - Handle CSS compilation and loading
  - Manage asset dependencies and versioning
  - Localize JavaScript with WordPress data

## Usage

The frontend scope handles all client-side assets needed for the React-based admin interface. The Assets class ensures proper loading order and dependencies for the development toolkit's frontend
components.

## Dependencies

- WordPress Scripts API
- React and ReactDOM
- WordPress Components library
