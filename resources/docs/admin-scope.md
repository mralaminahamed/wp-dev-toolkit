# WP Dev Toolkit - Admin Scope

This directory contains all admin interface related functionality for the WP Dev Toolkit plugin.

## Files

### Menu.php

- **Purpose**: Handles WordPress admin menu registration and page rendering
- **Responsibilities**:
  - Register admin menu pages
  - Render admin page containers for React app
  - Handle menu page routing

## Usage

The admin scope provides the backend interface for managing the plugin. The Menu class integrates with WordPress admin to provide access to the development toolkit features.

- WordPress Admin API
